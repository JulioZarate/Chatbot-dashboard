# Andrea · Dashboard de inversión en bolsa

Dashboard interactivo en HTML sobre inversión en bolsa, con el agente de voz **Andrea** (ElevenLabs, con RAG) embebido y un chatbot de texto que solo responde con la información del propio dashboard.

- **Sitio (GitHub Pages):** https://juliozarate.github.io/Chatbot-dashboard/
- **Probar el agente de voz:** https://elevenlabs.io/app/talk-to?agent_id=agent_8301m5nkww06eg0sxdv6g6077epm

## Contenido
- Conceptos clave (acción, ETF, horizonte, riesgo)
- Calculadora de interés compuesto con gráfica
- Riesgo vs rendimiento por tipo de instrumento (filtrable)
- Simulador de portafolio con perfil de inversionista
- Cómo empezar a invertir desde México, glosario con buscador y preguntas frecuentes
- Widget de voz de ElevenLabs (esquina inferior derecha)
- Chatbot restringido al contenido del HTML (esquina inferior izquierda); cita la sección de donde sale cada respuesta y rechaza preguntas fuera del tema

> Contenido educativo. No constituye asesoría de inversión.
